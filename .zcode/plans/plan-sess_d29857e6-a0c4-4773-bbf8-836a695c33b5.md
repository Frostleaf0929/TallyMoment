## 二、技术选型（已与你确认）

- **Tauri 2**（Rust 核心 + 系统自带 WebView2 渲染界面）+ **Vue 3 + TypeScript + Vite + Pinia + Naive UI**（现代简洁组件库）+ **ECharts**（图表）
- 输出：**单个绿色 exe（约 5~15MB），免安装、免管理员权限**，数据存 exe 旁 `Data/` 目录
- 项目协议：MIT

## 三、总体架构

- **Rust 核心**：tracker（每秒检测前台窗口，切换时写入记录区间；空闲检测；键鼠活跃度）＋ scheduler（清单到点提醒）＋ storage（SQLite 读写）
- **前端主窗口**：今日时间线、应用排行、小时分布图、专注统计、清单管理、设置
- **桌宠窗口**（M5）：独立透明置顶+点击穿透小窗，猫随键鼠活动敲键盘，显示今日专注时长
- **托盘**：常驻托盘，显示今日累计时长，右键菜单（暂停记录/打开面板/退出）

## 四、数据模型（SQLite）

`apps`（应用维表）、`segments`（前台区间原始记录）、`hourly_stats`/`daily_stats`（小时/日汇总，带唯一约束防重复——吸收 Tai 的坑）、`checklist`（清单项：起止时间/重复/提醒）、`input_stats`（键入次数/点击数，**只记次数不记内容**）、`settings`。

## 七、已知风险与对策

- **路径含中文和 `#`**：Rust/Cargo 偶发路径兼容问题。先在工作区子目录开发，若编译报路径错误则迁到纯英文路径（如 `E:\Dev\TallyMoment`），记录文档位置不变
- 全局输入监听可能被杀软提示 → 用主流库并说明用途
- 键盘统计**只记次数不记内容**（隐私底线，界面注明）
- 数据目录检测到不可写时自动回退 `%AppData%\TallyMoment` 并提示
- 首次 Rust 编译较慢（10~20 分钟，属正常）
