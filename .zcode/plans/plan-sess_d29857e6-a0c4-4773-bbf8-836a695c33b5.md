# 拾刻 · 框架重构计划（9 点反馈 → 5 批次）

## 定位修正（你的第 1 点）

拾刻 ≠ Tai 克隆。重新定位为**效率伴侣**：时间记录 + 待办提醒 + 洞察 + 桌宠 + 个性化，五大支柱均衡。新信息架构（侧边栏可收展）：
**概览**（新：今日摘要 + 当前专注大分区 + 待办速览 + 洞察精选）｜**时间**（热力时间线+分布+排行+历史 日/月/年）｜**待办**（任务+提醒规则+完成率）｜**洞察**（心流推断+频率区间分析）｜**桌宠**（设置+模型导入）｜**个性化**（主题/强调色/毛玻璃）｜**数据**（导出/恢复/删除）

三个未答问题按推荐执行（可否决）：① Tai 对齐 = data.db + CSV 双导出 ② 先做 UI 底座 ③ 桌宠逐键编码"实时使用、不落库不显示"

## 批次 1：UI 底座（先做，后续功能直接长在新皮肤上）

- **设计 token 体系** theme.css（学 Catrace 单一真源）：柔化去饱和配色（深色基调 + 单强调色，弃艳色）；卡片统一半透明 + 毛玻璃（Tauri 内置窗口 Acrylic/Mica 效果 + CSS backdrop-filter）；圆角/描边/阴影全套 token
- **Solar Line Duotone 图标**：svgrepo 挑 ~16 个（逐个核对许可），做 Icon.vue 内联组件，替换现有裸文字
- **侧边栏收展**：展开 200px / 收成图标条 64px，状态记忆
- **个性化页 v1**：主题（暗/亮/跟随系统）、强调色（4~6 选）、毛玻璃开关、桌宠显隐
- **今日页重构**：时间线改**分钟级热力条**（柔色阶，替代割裂色块）；"当前使用"升级为 **当前专注大分区**（flow-insight 式：当前应用、已持续、今日第几个专注块、状态标签 专注/碎片/休息）；24h 分布改 Tai 式柔和单色渐变堆叠
- uiverse 5 链接（403 被拦）实现时换抓取通道取源码，其毛玻璃/微交互手法融入 token

## 批次 3：洞察升级（点 6，对标 flow-insight）

- **专注块重构**：segments 间隔 <5 分钟归并成块 → 每块算时长/切换密度/键鼠密度/时段
- **心流推断**（规则版，界面标注"推断"）：块 ≥25min 且低切换 → 心流；中等 → 专注；短碎 → 碎片；无输入 → 休息
- 新视图：使用频率（键鼠逐日折线）、使用区间（每日首末活跃/时段带）、心流时间线（块着色）
- 洞察卡片改"分析 + 建议"双段式，减少数字罗列

## 批次 4：数据与可靠性（点 7、9）

- 移除"从 Tai 导入"入口；新增 **Tai 对齐导出**：① 生成 Tai 可直接使用的 data.db（App/DailyLog/HoursLog 三表——调研确认 Tai 启动自检会自动补齐其余表）② Tai 同列 CSV（每日/时段，列：日期/应用/描述/时长秒/分类）。调研确认 Tai 无导入功能，不冲突
- **删除数据**：按范围（今天/全部/指定应用），二次弹窗确认
- **开机自启**：tauri-plugin-autostart 2.x（Tauri 官方插件，新依赖——本计划批准即含）
- **键鼠落库 30s → 5s**：崩溃/强杀最多丢 5 秒（你说的"退出就没了"根因修复）；JSON 导出/恢复保留

## 批次 5：桌宠增强（点 8，对标新版 BongoCat）

- **桌宠设置页**：缩放/透明度/置顶/点击穿透/镜像翻转/随机表情/位置重置（对标 BongoCat 设置清单子集）
- **Mver 模型包导入**：文件夹/ZIP 入口；解析 config.json + img/{standard} 分层素材 + **VK 码→帧映射矩阵**（调研已拿到完整格式规范）；模型列表管理（启用/删除/sha256 去重）；钩子改传 VK 码——**仅实时选帧，不落库不显示**（隐私口径已在上方声明）
